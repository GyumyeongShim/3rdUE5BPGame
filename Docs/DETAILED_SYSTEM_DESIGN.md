# Gridventure: Detailed System Design Specifications

이 문서는 프로젝트의 하이브리드 게임성(RTS 건설 + 탄막 생존 + 그리드 인벤토리)을 구현하기 위한 핵심 시스템들의 상세 설계 및 기술 명세를 통합한 가이드입니다.

---

## 1. 그리드 인벤토리 시너지 로직 (Inventory Synergy Logic)

아이템 간의 위치 관계에 따른 보너스 스탯 계산 및 시너지 판정 로직을 정의합니다.

### 1.1 인접성 체크 알고리즘 (Adjacency Logic)
가방 내 2D 그리드에서 특정 아이템(`Owner`)을 기준으로 주변 아이템을 탐색합니다.
- **Direct (상하좌우):** (x±1, y), (x, y±1)
- **Diagonal (대각선):** (x±1, y±1)
- **Surrounding (주변 8칸):** Direct + Diagonal
- **Row/Column (행/열):** 같은 가로줄 혹은 세로줄 전체

### 1.2 모양 고려 (Shape-Aware Check)
- 아이템이 여러 칸을 차지하는 경우(L자, T자 등), 아이템을 구성하는 **모든 칸의 외곽**을 인접 영역으로 간주합니다.

### 1.3 태그 기반 시너지 시스템
아이템에 부여된 `Tag`를 활용하여 조건부 효과를 발동합니다.
- **예시 조건:** `AdjacentTo(Tag: "Metal", Count: 2)` -> `Defense +5`
- **예시 효과:** `IncreaseStat(Target: "Weapon", Value: 10%)` -> 주변 모든 무기 데미지 상승

### 1.4 순환 참조 및 무한 루프 방지
- **Base-First 계산:** 모든 아이템의 기본 스탯(Base)을 먼저 합산합니다.
- **Single Pass:** 시너지 계산은 정해진 순서대로 단 한 번만 수행하여 무한 루프를 방지합니다.

## 2. 하이브리드 데이터 브릿지 (Meta-Progression Bridge)

마을(건설/경영)과 필드(전투/생존) 간의 데이터 흐름과 영구 성장 시스템을 정의합니다.

### 2.1 메타 성장 데이터 구조
- **영구 보정치 (Permanent Modifiers):** 건물 레벨에 따른 전체 스탯 % 상승 (예: 대장간 Lv.2 -> 모든 무기 공격력 +5%).
- **연구/기술 트리:** 채집 효율, 이동 속도, 초기 가방 크기 확장 데이터 관리.

### 2.2 레벨 간 데이터 전송 (Data Persistence)
- **마을 -> 필드 (Entry):** 현재 마을 발전 단계 보너스와 인벤토리 장착 아이템 리스트를 `GI_Gridventure`에 저장 후 필드로 전달.
- **필드 -> 마을 (Exit):** 필드에서 획득한 자원(나무, 돌 등)과 특수 아이템(유물 등)을 마을 데이터베이스에 영구 반영.

---

## 3. 대규모 개체 최적화 (Mass Object Optimization)

수백 마리의 적과 투사체를 원활하게 처리하기 위한 기술적 최적화 방안입니다.

### 3.1 오브젝트 풀링 (Object Pooling)
- **PoolManager:** 적 및 투사체를 매번 생성/파괴하지 않고 미리 생성된 풀에서 활성화/비활성화하여 CPU 부하를 방지합니다.

### 3.2 경량화된 AI 및 물리
- **Movement:** 복잡한 경로 탐색 대신 플레이어 방향으로의 단순 벡터 이동과 `Overlap` 기반의 충돌 판정을 사용하여 연산량을 줄입니다.
- **Tick Throttling:** 카메라 거리나 개체 수에 따라 업데이트 주기(Tick Rate)를 동적으로 조절합니다.

### 3.3 렌더링 최적화
- **Instanced Static Mesh (ISM):** 동일 외형의 개체들을 인스턴싱으로 처리하여 드로우 콜을 획기적으로 낮춥니다.

---

## 4. 입력 컨텍스트 전환 (Input Context Switching)

게임 모드(마을, 필드, 인벤토리)에 따른 조작 체계의 동적 전환을 정의합니다.

### 4.1 조작 모드 정의
- **IMC_Town:** 마우스 기반 건물 선택 및 화면 드래그 이동.
- **IMC_Field:** WASD 이동 및 액션 스킬 중심의 조작.
- **IMC_Inventory:** 가방 내 아이템 드래그 & 드롭 및 회전(R 키).

### 4.2 상태별 전환 로직
- **Focus Path:** 입력이 UI 레이어에서 소비되었는지 판별하여, 가방 정리 중 캐릭터가 원치 않는 공격을 수행하는 것을 방지합니다.

---

## 5. 테트리스 루트 시스템 (Tetris Loot System)

적 처치 시 드롭되는 아이템의 모양(Shape) 생성 및 획득 로직입니다.

### 5.1 아이템 모양 생성 (Shape Generation)
- **그리드 정의:** 아이템 데이터에 2x2, L-Shape 등 2D 그리드 정보를 포함시킵니다.
- **랜덤 변형:** 획득 시 혹은 드롭 시 모양이 랜덤하게 회전되어 나올 수 있도록 설계합니다.

### 5.2 필드 드롭 시각화 및 획득
- **Loot Preview:** 지면의 드롭 아이템 위에 해당 아이템의 그리드 점유 모양을 홀로그램으로 표시하여 직관성을 높입니다.
- **배치 제한:** 가방 내에 해당 모양이 들어갈 수 있는 빈 공간이 있을 때만 획득 가능하도록 처리합니다.
